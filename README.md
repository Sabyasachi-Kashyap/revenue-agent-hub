# Revenue AI Agent Hub — Cloud Deployment & Setup Guide

This platform is 100% cloud-ready and can be stored/hosted on any cloud provider for **24/7 autonomous operation** without needing your local laptop to stay powered on.

---

## ⚡ Option 1: Free 1-Click Cloud Deployment (Vercel — Recommended)

1. **Push to GitHub**:
   Upload this project folder (`revenue-agent-hub`) to a new repository on [GitHub](https://github.com).
2. **Deploy on Vercel**:
   - Go to [Vercel.com](https://vercel.com) and log in.
   - Click **Add New Project** → Select your GitHub repository.
   - Click **Deploy** (Vercel automatically detects Vite + React and `vercel.json`).
3. **Done!** Your hub will be live 24/7 at `https://revenue-agent-hub.vercel.app`.

---

## 🌐 Option 2: Netlify Cloud Hosting

1. Sign up on [Netlify.com](https://netlify.com).
2. Drag & drop the `dist` folder generated by running `npm run build`, OR connect your GitHub repository.
3. Your hub will be live 24/7 with SSL enabled.

---

## 🐳 Option 3: Docker / Render / AWS / Cloud Run

A pre-configured `Dockerfile` is included. To build and run locally or in cloud containers:

```bash
docker build -t revenue-agent-hub .
docker run -p 8080:80 revenue-agent-hub
```

---

## 💻 Option 4: Local Dev Execution

To run locally anytime:

```bash
npm install
npm run dev
```

App runs on: `http://localhost:3000`
